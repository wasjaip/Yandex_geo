# Yandex Geo — нормализация географических названий

Проект по поиску и унификации географических названий с опорой на GeoNames.

Задача — приводить разные варианты написания одного географического объекта к единому представлению, в том числе при наличии сокращений и опечаток.

Примеры входных значений:

```text
СПб
Санкт-Петербург
С.-Петербург
Сант-Питербург
```

Целевой результат — определить соответствующий объект GeoNames и вернуть нормализованное название.

## Задача

В рамках проекта требовалось:

- подготовить данные GeoNames;
- загрузить и организовать данные в PostgreSQL;
- построить рабочий датасет;
- протестировать разные подходы к поиску похожих названий;
- подготовить модуль, который можно подключить к внешней системе.

## Стек

`Python` · `PostgreSQL` · `GeoNames` · `NLP` · `embeddings` · `similarity search`

## Подход

Решение строится вокруг поиска наиболее похожих географических объектов по текстовому представлению названия.

Основные направления экспериментов:

- нормализация строк;
- поиск по сокращениям и вариантам написания;
- семантические эмбеддинги;
- хранение эмбеддингов;
- ранжирование кандидатов по степени сходства.

## Конфигурация

Параметры подключения к PostgreSQL не должны храниться в коде или коммититься в репозиторий.

Создайте локальный файл `.env` на основе шаблона:

```bash
cp .env.example .env
```

Шаблон содержит только безопасные значения для локальной разработки:

```text
DB_DRIVER=postgresql
DB_HOST=localhost
DB_PORT=5432
DB_NAME=geonames
DB_USER=postgres
DB_PASSWORD=change_me
```

Файл `.env` исключён через `.gitignore`.

> В старом экспериментальном модуле `work/geo_mod.py` исторически остались параметры тестового подключения. Перед реальным использованием этот участок следует перевести на чтение переменных окружения.

## Возможные варианты развития

Для промышленного использования рассматривались:

- хранение эмбеддингов в PostgreSQL;
- Redis для кэширования;
- Elasticsearch для поиска;
- отдельное хранилище эмбеддингов;
- GPU-ускорение;
- иерархический поиск и предварительное сокращение пространства кандидатов.

Проект демонстрирует полный путь от внешнего справочника и подготовки данных до прикладного модуля поиска и нормализации географических сущностей.
